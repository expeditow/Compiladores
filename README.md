# C-Like Compiler (Intermediate Code Generator)

This project consists of a robust compiler that translates a high-level language with custom syntax into functional C code. The system performs **lexical, syntactic, and semantic analysis**, integrating a code generator that handles **dynamic memory management and complex control flow**.

---

## Technical Features

### 1. Type System and Semantics

**Type Inference**  
The compiler performs automatic type promotion (e.g., `int` to `float`) in mixed arithmetic operations to ensure precision.

**Explicit Casting**  
Support for manual type conversion using the syntax `(type) value`.

**Function Validation**  
Strict verification of function signatures, ensuring that both the **number and types of arguments** in a function call exactly match the declaration.

**Increment/Decrement Operators**  
Faithful implementation of **prefix and postfix increment/decrement operators**, using temporary variables to guarantee the correct order of evaluation and returned value.

---

### 2. Memory Management and Strings

Unlike simplified implementations, this project handles **strings using dynamic allocation**.

**Automatic Allocation**  
Uses `malloc` to initialize strings and store the results of concatenation operations.

**Memory Leak Prevention**  
Implements a tracker for allocated variables that automatically inserts `free()` calls at the end of the `main` scope or before pointer reassignments.

**Native Operations**  
Supports string concatenation using the `+` operator and automatically includes internal helper functions such as `meu_strlen`.

---

### 3. Data Structures and Control Flow

**Arrays and Matrices (1D and 2D)**  
Support for multidimensional arrays with **linear address calculation** for mapping into C memory:


final_index = (i × total_columns) + j


**Loop Control**  
Uses **label stacks** to correctly manage `break` and `continue` statements within nested loop contexts (`while`, `do-while`, `for`).

**Exponentiation**  
Implements the `**` operator with **right associativity**, integrated with a `potencia_helper` function generated in the output code.

---

## Project Structure

**parser.y**  
Bison grammar containing translation rules, precedence definitions, and semantic actions written in C++.

**y.tab.h**  
Header generated by Bison containing token definitions (`kinds`) and constants for integration with the lexical analyzer.

**Symbol Table**  
Implemented using a **stack of maps (`std::map`)**, enabling support for multiple scopes and **variable shadowing**.
